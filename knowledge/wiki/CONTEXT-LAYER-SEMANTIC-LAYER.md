# Context layers, semantic layers, and catalogs

> AI-generated synthesis from Charlotte Ledoux's public writing. Not authored or endorsed by her. No paid templates are included.

The later corpus reframes governance around the context that humans and agents actually read: catalogs document, semantic layers execute, and context stacks make answers trustworthy.

## Public-grounded takeaways
- Catalogs document; semantic layers execute; context layers feed agents.
- A governed context stack can include wiki knowledge, semantic definitions, evidence, permissions, and rules.
- Semantic layers matter when several tools or agents need the same governed definition.
- Catalogs fail when the content is poor or disconnected from daily workflow.
- The long-term shift is from governing raw data to governing the context that decisions read.

## Synthesis / inference
- This is the most visible 2026 reframing in the corpus.
- The public pieces move from document-centric governance to executable meaning and agent-ready context.
