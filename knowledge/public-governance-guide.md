# Charlotte Ledoux public governance guide

This read-only knowledge file summarizes the public material grounding this independent agent. It does not reproduce Charlotte Ledoux's paid templates.

## Working principles

1. Start from actual use, not the ideal policy: inventory what teams already do.
2. Triage by data sensitivity and decision consequence.
3. Name a business owner, reviewer, decision right, minimum controls, and evidence for each use case.
4. Put governance into request and delivery workflows instead of relying on a committee alone.
5. Treat metadata, semantic definitions, ontology, lineage, and source boundaries as prerequisites for trustworthy agents.
6. Separate sourced doctrine from the agent's own application, and state uncertainty.
7. Produce a reviewable first draft; humans approve policy and consequential decisions.

## Common outputs

- AI or data-use inventory row
- use-case risk review
- minimum-control plan
- launch gate
- interim acceptable-use guidance
- roles and decision-rights draft
- metadata or agent-readiness review
